# 틱택토 게임

- **이름** : 이예준
- **소속** : 대구가톨릭대학교 AI빅데이터공학과

## 요약
두 명의 플레이어가 번갈아 가며 3×3 크기의 게임판에 'O'와 'X'를 표시하여 가로, 세로, 대각선 중 한 줄을 먼저 완성하면 승리하는 콘솔 기반 틱택토(Tic-Tac-Toe) 게임을 C언어로 구현하였다. 1~9번 숫자를 입력받아 2차원 배열 좌표로 변환하는 기능, 중복 및 범위 외 입력 예외 처리, 승리 및 무승부 판정 기능을 제공한다.

## 1. 서론
본 보고서는 C언어를 활용한 콘솔 기반 틱택토(Tic-Tac-Toe) 게임의 설계 및 구현 과정을 설명한다. 2장에서는 프로젝트와 관련된 이론 및 배경을 다루고, 3장과 4장에서는 프로그램의 기획·설계와 핵심 코드 구현 내용을 기술한다. 이후 5장과 6장에서는 실제 실행 결과와 동작 분석을 정리하고, 7장과 8장에서 결론 및 참고문헌을 제시한다.

## 2. 관련 연구
### 2.1 틱택토(Tic-Tac-Toe) 게임 규칙
틱택토는 두 명의 플레이어가 3×3 격자판 위에서 각각 `'O'`와 `'X'` 기호를 번갈아 놓으며 진행하는 추상 전략 보드게임이다. 자신의 기호를 가로, 세로, 또는 대각선 방향으로 3칸 연속 배치하는 플레이어가 즉시 승리하며, 9칸이 모두 채워질 때까지 승자가 나오지 않으면 무승부로 종료된다.

### 2.2 C언어 2차원 배열을 활용한 격자 표현
C언어에서 2차원 배열(`char board[3][3]`)은 행(Row)과 열(Column)의 인덱스를 통해 표 형태의 데이터를 직관적으로 표현할 수 있는 자료구조이다. 본 프로젝트에서는 3×3 게임판의 각 칸에 초기 문자로 `'1'`부터 `'9'`까지를 할당하여 사용자가 위치 번호를 쉽게 파악할 수 있도록 하고, 게임 진행에 따라 해당 칸의 문자를 `'O'` 또는 `'X'`로 갱신하는 방식을 적용하였다.

### 2.3 몫과 나머지 연산을 통한 1차원 입력의 2차원 좌표 매핑
사용자는 직관적인 선택을 위해 1부터 9까지의 단일 숫자를 입력하지만, 내부 배열은 `0`부터 `2`까지의 행과 열 인덱스를 사용한다. 이를 연결하기 위해 입력값(`num`)에서 1을 빼서 `0~8` 범위로 보정한 뒤, 가로 크기인 `3`으로 나눈 **몫**과 **나머지**를 활용하는 좌표 변환 공식을 적용하였다.
- **행(Row) 인덱스** : `(num - 1) / 3` (정수 나눗셈의 몫을 통해 `0`, `1`, `2` 행 결정)
- **열(Column) 인덱스** : `(num - 1) % 3` (나머지 연산을 통해 `0`, `1`, `2` 열 결정)

## 3. 프로그램 설계
### 3.1 계획 및 기획 배경
초기에는 C언어 프로그래밍에 대한 자신감이 붙으면서 시간이 다소 오래 걸리더라도 난이도가 있는 게임을 구현해 보고자 **오목**을 프로젝트 주제로 고려하였다. 그러나 콘솔 환경에서 흑돌과 백돌을 직관적으로 구분하여 출력하는 방안을 고민하던 중, 돌 대신 `'O'`와 `'X'` 문자로 표기하는 아이디어를 떠올리게 되었다. 이를 계기로 `'O'`와 `'X'` 기호를 핵심 요소로 사용하는 **틱택토(Tic-Tac-Toe)** 게임을 구현하는 방향으로 주제를 구체화하여 기획하였다.

### 3.2 자료구조
- `char board[3][3]` : 3×3 게임판의 각 칸 상태를 저장하는 2차원 문자 배열로, 초기값은 `'1'`~`'9'`로 설정하여 사용자가 선택할 위치를 직관적으로 확인할 수 있도록 구성하였다.
- 주요 상태 변수 : 게임 종료 여부를 판별하는 `gameResult`(진행 중 `0`, 승리 시 `1`), 진행된 턴 수를 세는 `turn`(0~9), 현재 차례를 나타내는 `player`(1 또는 2) 및 표시 문자 `mark`(`'O'` 또는 `'X'`)를 사용한다.

### 3.3 함수 구성
- `void printBoard()` : 현재 `board[3][3]` 배열에 저장된 게임판 상태를 격자 형태로 콘솔에 출력한다.
- `int checkWin()` : 가로 3줄, 세로 3줄, 대각선 2줄의 문자가 모두 일치하는지 검사하여 승리 조건 달성 시 `1`, 미달성 시 `0`을 반환한다.
- `int main()` : 게임 안내 출력, 턴 반복 제어, 사용자 번호 입력 및 2차원 배열 인덱스 변환, 입력값 유효성 검사, 최종 승패 및 무승부 판정을 수행한다.

## 4. 프로그램 구현
### 4.1 좌표 변환 및 입력 검증
사용자가 1에서 9 사이의 번호(`selectNumber`)를 입력하면 1을 뺀 뒤 3으로 나눈 몫과 나머지를 이용해 2차원 배열의 행(`row`)과 열(`column`) 인덱스로 변환한다. 또한 입력값이 1에서 9 범위 내인지, 해당 칸에 이미 `'O'` 또는 `'X'`가 놓여 있지 않은지 검증한다.

```c
row = (selectNumber - 1) / 3;    // 입력한 번호의 행을 행렬식(0~2)으로 변환
column = (selectNumber - 1) % 3; // 입력한 번호의 열을 행렬식(0~2)으로 변환

if (selectNumber >= 1 && selectNumber <= 9 && board[row][column] != 'O' && board[row][column] != 'X') {
    board[row][column] = mark;
    turn++;
    gameResult = checkWin();
}
else
    printf("선택할 수 없는 번호입니다. 다른 번호를 선택하세요.\n");
```
### 4.2 승리 조건 판정 (checkWin)
반복문을 통해 가로와 세로 줄의 일치 여부를 먼저 확인하고, 이어서 두 방향의 대각선 일치 여부를 검사한다.

```c
int checkWin() {
    for (int i = 0; i < 3; i++) {
        if (board[i][0] == board[i][1] && board[i][1] == board[i][2]) // 가로 한 줄 완성
            return 1;
        if (board[0][i] == board[1][i] && board[1][i] == board[2][i]) // 세로 한 줄 완성
            return 1;
    }

    if (board[0][0] == board[1][1] && board[1][1] == board[2][2]) // '\' 대각선 완성
        return 1;
    if (board[0][2] == board[1][1] && board[1][1] == board[2][0]) // '/' 대각선 완성
        return 1;

    return 0; // 아직 완성 없음
}
```

## 6. 결과 분석 및 토의
구현된 틱택토 게임을 실행하여 테스트한 결과, 플레이어 1(`O`)과 플레이어 2(`X`)의 턴 교대, 1~9 범위 밖의 숫자 및 이미 선택된 칸에 대한 예외 안내, 가로·세로·대각선 승리 판정, 그리고 9턴 종료 시 무승부 처리까지 핵심 게임 로직이 모두 정상적으로 동작함을 확인하였다.

다만 프로그램을 테스트하는 과정에서 **숫자가 아닌 문자(예: 알파벳이나 특수문자 등)를 입력할 경우 오류가 발생하는 한계점**을 발견하였다. 현재 코드에서는 `scanf("%d", &selectNumber);`로 정수 입력만 처리하도록 구현되어 있어, 실수로 문자를 입력하면 입력이 정상적으로 처리되지 않고 안내 문구가 계속 반복 출력되는 현상이 나타난다. 이번 구현에서는 기본적인 숫자 범위와 중복 선택 예외 처리까지 반영하였으며, 문자 입력 시 발생하는 오류의 정확한 원인과 이를 해결하기 위한 입력 처리 방법은 추후 학습을 통해 알아보고 개선할 예정이다.

## 7. 결론
이번 프로젝트를 통해 C언어의 기본 문법인 2차원 배열, 반복문, 조건문, 그리고 함수 분리를 실제 동작하는 하나의 완성된 게임 프로그램으로 엮어내는 경험을 할 수 있었다. 특히 사용자가 입력한 1~9의 숫자를 몫과 나머지 연산을 통해 2차원 배열의 행과 열 인덱스로 변환하는 과정을 직접 설계하면서, 수학적 논리가 코드의 간결함과 직관성에 미치는 영향을 깊이 이해하게 되었다. 비록 문자 입력 시 버퍼 처리와 같은 예외 상황 보완점이 남았지만, 프로그램의 기획부터 구현, 테스트, 오류 분석에 이르는 전체 개발 과정을 스스로 경험하며 프로그래밍에 대한 실질적인 문제 해결 역량을 기를 수 있었다. 앞으로는 예외 처리의 완성도를 높이고, 나아가 컴퓨터와 대전할 수 있는 알고리즘이나 처음 기획했던 오목 게임 등 더 확장된 프로젝트에도 도전할 계획이다.
